FLEXYTRACKER OVERLAY

Este proyecto genera un instalador de Windows (.exe) que abre https://flexytracker.netlify.app/.

Incluye una ventana sin marco, movible y redimensionable, siempre visible sobre otras ventanas,
con botones para recargar, alternar el modo siempre visible, minimizar y cerrar. Usa la misma
web y las mismas salas de FlexyTracker; no crea una copia local.

Este ZIP contiene el proyecto fuente, no el .exe compilado. La compilación para Windows se
realiza automáticamente en GitHub Actions. Consulta GUIA_COMPILACION.txt.
Para usarlo con League of Legends, configura el juego en modo ventana sin bordes. La visibilidad
sobre el juego puede variar según el modo de pantalla y la configuración de Windows.
